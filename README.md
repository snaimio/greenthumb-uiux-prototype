**GreenThumb** is an all-in-one digital gardening companion and community platform designed to bridge urban gardeners, botanical enthusiasts, and beginners with intelligent plant care, local community garden plots, workshop events, and plant marketplace resources.

---

## 🎨 Design System & Visual Architecture

The visual language balances organic, natural tones with modern, accessible interface components:

- **Primary Colors:** Deep Forest Green (`#144D37`), Fresh Leaf Green (`#2C8B59`), Sage Mint (`#85C19C`)
- **Accent & Secondary:** Terracotta / Warm Coral (`#E76F51`), Sunrise Sand (`#F4E2C7`), Golden Sunflower (`#F4A261`)
- **Typography & Components:** High-legibility sans-serif type scaling, accessible contrast ratios (WCAG AAA compliant), rounded modular cards, and custom iconography for watering, sunlight, and humidity indicators.

## 🚀 Opening the Figma Files

1. Clone or download this repository:
   ```bash
   git clone https://github.com/snaimio/greenthumb-uiux-prototype.git
   ```
2. Open **[Figma](https://www.figma.com/)** (in browser or desktop app).
3. Navigate to **Your Files** or **Drafts**, click **Import file** (or drag and drop), and select any `.fig` file from the `/design` directory:
   - `design/AppPrototype_UIUX_Sheikh_Assignment4.fig`
   - `design/Prototype_Assignment3_UIUX_SheikhNaim.fig`
   - `design/SheikhNaim_UI_UX_Assignment2.fig`
4. Enter **Present / Prototype Mode** (`Cmd + Option + Enter` / `Ctrl + Alt + Enter`) to interact with the screens and transitions.
